# FarmerBot 4.0 — Complete Farming Automation Simulator

**Версия:** 4.0.0-alpha.1 · разработка продолжается в ветке `farmerbot-4.0`

FarmerBot 3.0 развивается непосредственно поверх FarmerBot 2.1. Это не новая игра с нуля: сохраняются Three.js сцена, игровой цикл, четыре роли роботов, десять культур, задания FarmerBot 2.1, строительство, исследования, A* навигация и загрузка старых сохранений.

## Что действительно реализовано в Alpha 1

- IDE с подсветкой синтаксиса, номерами строк и подсветкой текущей команды.
- Автодополнение только поддерживаемых команд, датчиков, встроенных функций, переменных и пользовательских функций; Enter/Tab принимает выбранную подсказку.
- Проверка синтаксиса и известных вызовов; runtime-ошибки привязываются к строке.
- Глобальные и локальные переменные с типами, подсветкой изменившихся значений, а также списки функций, роботов и реальный стек вызовов.
- Отдельные списки пользовательских функций, роботов, состояния отладчика и стека вызовов.
- Реальные точки останова, pause, step, resume, stop и reset через gate DSL-интерпретатора; показываются текущая и следующая инструкции.
- Поддерживаются вложенные пользовательские функции и возвращаемые значения. Без `eval()` и `new Function()`; ограничения шагов, циклов и глубины вызовов сохранены.

## FarmerBot 4.0 — текущий этап

Работа продолжается поверх исходного проекта FarmerBot 3.0. Существующие сцена, роботы, DSL, фермерство, строительство, исследования, биомы, погода и автоматизация сохраняются.

- Добавлены до 12 независимых слотов ферм с переключением и созданием из экрана выбора биома.
- Слоты изолируют миры, режимы, seed, разблокировки регионов и профили миров.
- Старое сохранение v2–v8 переносится в первый слот без удаления старых данных; версии v9 сохраняют соединения водопровода.
- Повреждённые данные не перезаписываются автосохранением.
- Добавлена кампания на 12 глав с целями и наградами.
- Добавлен симулируемый водопровод: скважины, резервуары и насосы соединяются трубами; насосы требуют питание, а мороз останавливает поток.
- Сцены гор и пустыни получили рельеф и ориентиры; грядки используют отдельные модели арбузов, пшеницы и кукурузы.
- Последняя проверка исходников: `node --test` — 117/117; синтаксическая проверка `src/main.js`, `src/data.js` и `src/water-network.js` прошла.
- Ручная проверка Safari/iPad и браузерные сценарии ещё не выполнены.

Это промежуточная альфа. Остальные системы спецификации будут реализовываться поэтапно; наличие старых панелей или данных каталога не считается доказательством завершённой механики.

## Структура проекта

```text
index.html
src/
  main.js       # Three.js сцена, игровой цикл, UI и сохранения
  language.js   # безопасный DSL-парсер и интерпретатор, debugger snapshots
  ide.js        # подсветка, диагностика, completion, панели IDE
  debugger.js   # точки останова и управление паузой/шагом
  data.js       # культуры, роботы, задания, здания, технологии
  navigation.js # A* и занятые клетки
  save-system.js # слоты ферм, миграция и проверка сохранений
programs/       # исходные примеры программ роботов
tests/          # тесты каталога, DSL, навигации, IDE, debugger и UI
backup_original/ # оригинальные файлы старой редакции, не изменялись
```

## Проверка

Требуется Node.js 18+.

```bash
npm test
node --check src/main.js
node --check src/language.js
node --check src/ide.js
node --check src/debugger.js
node --check src/data.js
node --check src/navigation.js
```

## Сохранения

Формат игрового объекта — v9; каждый мир хранится в отдельном слоте. Перенос поддерживает старые ключи v2–v8 и сохраняет исходные данные. Точки останова IDE хранятся отдельно на устройстве.
