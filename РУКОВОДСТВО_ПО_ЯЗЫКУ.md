# FarmerBot 3.0 Alpha 3 — руководство по программированию

## Основные команды
```python
move(1)
turn_left()
turn_right()
plant("carrot")
water()
harvest()
scan()
return_to_base()
transfer_to("waterbot", "carrot", 2)
transfer_from("harvestbot", "carrot", 1)
go_to_plot("ready")
go_to_plot("thirsty")
go_to_plot("empty")
refill_water()
sleep(2)
```

## Переменные, циклы и условия
```python
steps = 4
for i in range(steps):
    if can_plant("tomato"):
        plant("tomato")
    elif can_water():
        water()
    elif can_harvest():
        harvest()
    move(1)
```

## Собственная функция
```python
def farm_row():
    for i in range(5):
        if can_plant("carrot"):
            plant("carrot")
        elif can_water():
            water()
        elif can_harvest():
            harvest()
        move(1)

farm_row()
return_to_base()
```

## Сенсоры
- `can_plant("crop")`, `can_water()`, `can_harvest()`
- `get_energy()`, `get_position()`, `get_inventory()` или `get_inventory("carrot")`
- `get_plant_age()`, `get_water()`, `get_coins()`, `get_harvest()`
- `tile_state()`, `count_ready()`, `count_empty()`, `front_is_clear()`, `at_plot()`, `distance_to_plot()`
- `has_water()`, `scan()`, `has_ready_plot()`, `has_empty_plot()`, `has_thirsty_plot()`

## Роли роботов
- **FarmBot Basic** — универсальный.
- **WaterBot** — сажать и собирать не может; специализация — полив.
- **HarvestBot** — не поливает; специализация — сбор и большой груз.
- **DroneBot** — не сажает, не поливает и не собирает; перемещается и сканирует.

Робот должен иметь заряд и место в инвентаре. `return_to_base()` возвращает его на базу, восстанавливает часть энергии и разгружает груз на склад. `refill_water()` разрешена рядом с базой.

## 10 культур
`carrot`, `potato`, `tomato`, `corn`, `strawberry`, `eggplant`, `cucumber`, `cabbage`, `pumpkin`, `sunflower`.

У каждой культуры свои визуальные стадии, время роста, цена продажи и цена семян. Выбери культуру в магазине и купи семена. Посаженная культура растёт только после полива или дождя.

## Безопасность
Код обрабатывает собственный parser/interpreter и не исполняется через `eval()` или `Function()`. Есть лимиты интерпретатора/циклов/вызовов, проверка границ поля, запрет столкновений и остановка программы. Поддерживаются комментарии через `#`.

Роботы программируются независимо друг от друга. В панели «СЕТЬ» можно запускать несколько программ одновременно. `go_to_plot("ready")` ищет ближайшую доступную грядку с урожаем, `go_to_plot("thirsty")` — грядку, ожидающую полива, а `go_to_plot("empty")` — свободную грядку. Перемещение и возврат на базу используют A* и обходят здания и занятые роботами клетки.

В редакторе доступны текущая строка, пауза, шаг, продолжение и остановка программы.

## Передача ресурсов между роботами (Stage B)

```python
# Передать 2 моркови роботу waterbot
transfer_to("waterbot", "carrot", 2)

# Забрать 1 морковь у harvestbot
transfer_from("harvestbot", "carrot", 1)
```

Первый аргумент — ID робота (`farmbot`, `waterbot`, `harvestbot`, `dronebot`), второй — ключ культуры, третий — положительное целое количество. Передача выполняется только при достаточном запасе у отправителя и свободном месте у получателя; при ошибке инвентари не меняются.

## Автоматизация фермы (Stage B)

В панели «СТРОЙКА» размести солнечный или ветровой генератор, аккумулятор и потребителей. В списке построек нажми «⚡ КАБЕЛЬ» у первого, а затем у второго узла. Соединённые потребители получают питание с учётом приоритета; при дефиците мощности они отключаются. Аккумулятор накапливает избыток и отдаёт его при нехватке.

Для логистики размести конвейер, разветвитель/фильтр/буфер и приёмный склад. Нажми «⇢ ЛЕНТА» сначала на источнике, затем на следующем узле. Повторяй для каждого участка маршрута; несколько входов в один узел объединяются. Фильтр переключается между всеми культурами и отдельными культурами.

В панели «СЕТЬ» включи «АВТОДИСПЕТЧЕР». Он распределяет посадку, полив, сбор и возврат на базу между свободными роботами с учётом специализации, расстояния, заряда и запасов. Роботы возвращаются для разгрузки и подзарядки.
