# Руководство по программированию FarmerBot

## Быстрый старт

1. Нажми `⌘ КОД`.
2. Вставь программу в редактор или нажми `ПРИМЕР`.
3. Нажми `▶ ЗАПУСТИТЬ`.
4. Смотри журнал под кнопками: там есть сообщения, завершение и ошибки с номером строки.
5. `■ СТОП` останавливает выполнение; длительное ожидание проверяет остановку примерно каждые 0,1 секунды.

Программа и состояние фермы сохраняются в локальном хранилище браузера. На другом устройстве сохранение автоматически не переносится.

## Основы языка

### Команды робота

```python
move(1)        # шаг вперёд; число шагов можно указать в скобках
turn_left()    # повернуть налево на 90°
turn_right()   # повернуть направо на 90°
plant()        # посадить семя на ближайшей грядке
water()        # полить ближайшую грядку
harvest()      # собрать созревший урожай
wait(3)        # ждать 3 секунды
```

### Переменные и вычисления

```python
target = 3
target = target + 2
target += 1

if target >= 5:
    print("План достигнут")
```

Поддерживаются числа и строки, `+ - * / %`, скобки, сравнения `== != < > <= >=` и логические операторы `and`, `or`, `not`.

### Условия

```python
if can_harvest():
    harvest()
elif can_water():
    water()
else:
    print("Пока ждём")
```

### Циклы

```python
for index in range(4):
    move(1)

count = 0
while count < 3:
    move(1)
    count += 1
```

`range(4)` даёт 0, 1, 2, 3. Также доступны `range(start, stop)` и `range(start, stop, step)`. В циклах работают `break` и `continue`.

### Функции

```python
def care_for_plot():
    if can_plant():
        plant()
    elif can_water():
        water()
    elif can_harvest():
        harvest()

care_for_plot()
```

Функции могут принимать параметры и завершаться командой `return`.

```python
def move_many(amount):
    for n in range(amount):
        move(1)

move_many(3)
```

## Датчики и сведения о ферме

| Функция | Что возвращает |
|---|---|
| `can_harvest()` | Можно ли собрать урожай на ближайшей грядке |
| `can_plant()` | Пустая ли ближайшая грядка |
| `can_water()` | Можно ли полить ближайшую грядку и есть ли вода |
| `is_ready()` | Созрел ли урожай на ближайшей грядке |
| `get_water()` | Остаток воды |
| `has_water()` | Есть ли хотя бы одна единица воды |
| `get_coins()` | Число монет |
| `get_harvest()` | Количество собранного урожая |
| `tile_state()` | Состояние ближайшей грядки: `empty`, `seed`, `growing`, `ready` или `none` |
| `count_ready()` | Сколько грядок готовы к сбору |
| `count_empty()` | Сколько грядок пусты |
| `front_is_clear()` | Не выйдет ли следующий шаг за границу поля |
| `at_plot()` | Есть ли поблизости грядка |
| `distance_to_plot()` | Расстояние до ближайшей грядки |

Встроенные функции: `range`, `abs`, `min`, `max`, `floor`, `ceil`, `round`, `print`.

## Совместимость со старым кодом

Старые команды по одной на строку остаются поддержаны:

```text
MOVE 1
TURN LEFT
TURN RIGHT
PLANT
WATER
HARVEST
WAIT 3
```

## Ограничения безопасности

Интерпретатор не использует `eval` и не выполняет JavaScript из редактора. Ограничения на запуск защищают страницу от случайных бесконечных программ: максимум 5000 шагов интерпретатора, 1000 повторений цикла, 300 вызовов игровых действий и 250 клеток перемещения за один запуск. Ожидание ограничено 30 секундами за один вызов.
