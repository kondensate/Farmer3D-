# Установка FarmerBot 2.0 в GitHub Pages

Репозиторий: `kondensate/Farmer3D-`  
Ветка: `main`  
Адрес сайта: `https://kondensate.github.io/Farmer3D-/`

## Что должно оказаться в корне репозитория

Содержимое ZIP нужно распаковать и загрузить в корень репозитория, сохранив структуру:

```text
index.html
src/
  main.js
  language.js
  data.js
programs/
  farmbot_smart_row.bot
  waterbot_auto_irrigation.bot
  harvestbot_collect.bot
  dronebot_scan.bot
README.md
ROADMAP.md
РУКОВОДСТВО_ПО_ЯЗЫКУ.md
```

Папки `tests/` и `backup_original/` полезны для проверки и восстановления, но для запуска сайта не обязательны. Старые корневые `main.js` и `language.js`, если они уже есть в репозитории, можно оставить: новая страница их не использует.

## Загрузка с компьютера

1. Распакуйте ZIP.
2. Откройте репозиторий на GitHub и выберите ветку `main`.
3. Нажмите **Add file → Upload files**.
4. Перенесите файлы проекта, сохранив папки `src/` и `programs/`.
5. Создайте commit в ветку `main`.
6. В **Settings → Pages** проверьте, что публикация настроена из `main` и папки `/ (root)`.

## Если загружаете с iPad

На iPad удобнее открыть ZIP в приложении **Файлы** и распаковать его. Для загрузки всего набора с сохранением папок используйте GitHub Codespaces (если он доступен для аккаунта): откройте Codespace репозитория, загрузите ZIP в корень проекта через файловую панель редактора, затем в терминале выполните `unzip -o FarmerBot2_SmartFarm_Alpha1.zip -d .` и проверьте дерево файлов перед commit. Если Codespaces недоступен, потребуется загрузить файлы по отдельности через GitHub или выполнить этот шаг на компьютере.

После публикации откройте адрес GitHub Pages выше. Страница загружает Three.js с jsDelivr, поэтому для первого запуска нужен интернет. Сохранение игры хранится локально в браузере устройства.
